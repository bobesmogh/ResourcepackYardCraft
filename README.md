# ResourcepackYardCraft

YardCraft использует один накопительный серверный ресурс-пак. Каждый новый официальный выпуск включает действующие ресурсы предыдущей версии и утверждённые дополнения. Паки отдельных механик используются как компоненты сборки.

## Версии

- Архивы называются `YardCraft_ResourcePack_vN.zip`.
- Заголовок релиза — `YardCraft Resource Pack vN`, тег — `vN`.
- В Minecraft отображается `YardCraft | Resource Pack vN`.
- Официальная последовательность начинается с v4, затем v5, v6 и далее. Обозначения `vN-dev` и `vN-test.1` используются для тестовых сборок.

Для каждого выпуска проверяются совместимость с Minecraft, сохранность предыдущих ресурсов и работа в локальном клиенте. После публикации ZIP скачивается по прямой ссылке без авторизации, а SHA-1 рассчитывается по скачанному файлу. URL и SHA-1 указываются в описании релиза. Предыдущие версии и ссылки сохраняются для отката.
